## 低价机为什么能这么便宜

同样标注"2核2G"，月付 20 元和月付 200 元的机器，差别不在参数表上。

**CPU 是共享还是独享。** 一台 32 核物理机切出 128 个 vCPU，和只切 64 个，到你手里的实际算力完全不同。部分低价机型走积分制，基线性能可能只有标称的百分之十几，跑满几分钟就开始限流。

**带宽是独享还是峰值共享。** "100M 带宽"在共享端口和独享端口下是两回事。晚高峰能不能跑满，取决于这一条。

**流量模式。** 低价海外机最常见的分法：一种带宽大但有月流量上限，用完限速；另一种带宽小但不限流量。前者适合偶尔有突发下载、平时闲着的场景，后者适合需要长期稳定在线的站点。

**还有一类是 NAT 机型。** 和别人共用一个公网 IP，靠端口映射对外服务，常见给 15 个映射端口。便宜，但端口固定，后期加服务会受限。

**最后是续费价。** 首年 99 元的机器第二年卖 300 元还是 320 元，比首年价格重要得多。看到"三年只要 99"，先算一下三年之后。

## 挑之前先定三件事，再看四个指标

三件事：用户主要在哪、要不要备案、每月能接受多少预算。国内节点访问快，但要走备案流程；香港、日本、韩国、美国节点免备案，代价是延迟。

延迟的量级可以拿来参考：香港机房对大陆用户通常在 30–50ms，日本、韩国 50–80ms，美国西海岸 150–200ms，欧洲 250–350ms。欧洲节点做静态站、备份、海外业务没问题，做面向大陆用户的交互型站点就要想清楚。

四个指标按重要性排：

1. **线路质量**，比带宽数字更能决定体验。CN2、CMI、CUG、AS9929 这类优化线路在晚高峰的丢包和抖动明显小于普通国际带宽，同配置价格差几倍，往往就差在这里。
2. **内存**。VPS 卡不卡第一看内存。512MB 只够跑静态站，1GB 偏紧，2GB 是建站的舒适起点，4GB 以上才方便跑 Docker 和数据库。
3. **硬盘类型**。写"高效云盘"和"SSD 云盘"是两种东西，单价能差三四倍，IOPS 差距对数据库类应用是直接的。名字里带 NVMe 的更好。
4. **流量和限速规则**。流量用完后是限到 5M 还是限到 1M，能不能买流量包恢复，用不完的流量是否顺延到次月——这几条决定长期成本。

## 几个常见问题

**免备案的机器能放国内业务吗？** 技术上可以，但访问速度取决于线路优化程度，而且部分行业资质要求国内节点，这个要按自己业务判断。

**流量用完了会怎样？** 不同线路的限速值不一样，香港二区和五区是限到 5M，韩国首尔是限到 1M。可以买流量包恢复高速，也可以直接换不限流量版机型。另外雨云用不完的流量会顺延到次月，不会清零，这一点对流量波动大的业务友好。

**硬盘不够怎么办？** 可以弹性扩容，SSD 云盘大致在 0.3–0.4 元/GB/月，高效云盘约 0.1 元/GB/月。数据库类应用别省这一步，机械盘和 SSD 的 IOPS 差距会直接体现在响应时间上。

**能按月买吗？** 可以按天、按月，也可以年付。新项目建议先月付跑一两个月，确认线路和配置合适再转年付锁价格。

**独立 IP 要额外花钱吗？** 每台默认分配 1 个公网 IPv4，费用已包含在套餐价里。需要多个独立 IP 或高防 IP 时才额外计费，香港高防 IP 大致 30–40 元/月。
